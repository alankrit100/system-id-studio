A QUICK GUIDE

From measurements to a model

  1. Choose a data source. Import a CSV as-is, or select a first- or second-order system to simulate.
  2. If simulating, set the input. Adjust the signal and measurement conditions, then generate data.
  3. Fit a model. Choose ARX complexity, then estimate its coefficients.
  4. Check the fit. Compare held-out measurements with the prediction and inspect the errors.

Importing skips simulation. The first- or second-order selection does not change an imported file. CSV columns: time, input, output.
